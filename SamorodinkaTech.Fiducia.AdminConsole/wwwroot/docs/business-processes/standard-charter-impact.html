Параметры устава — влияние на бизнес-процессы

Параметры устава юридического лица определяют, какие организационные мероприятия (задачи) будут автоматически включены в шаблон при создании组织ного мероприятия. Параметры задаются на вкладке «Нетиповой устав» страницы ЮЛ.

Параметры устава

Параметр Описание Влияние на бизнес-процессы
Выход участника Разрешён ли выход участника из общества Влияет на обязательность задачи «Уведомление о выходе участника»
Переход доли к участникам Требуется ли согласие участников при переходе доли между участниками Определяет процедуру уведомления при сделках между участниками
Переход доли к третьим лицам Требуется ли согласие участников при продаже доли третьему лицу Определяет процедуру уведомления при продаже доли третьим лицам
Преимущественное право покупки Есть ли у участников преимущественное право перед третьими лицами Запускает обязательную рассылку оферт с дедлайном 30 дней
Переход доли наследникам Разрешён ли переход доли наследникам без согласия Влияет на процедуру наследования доли
Исполнительный орган Тип: A — гендиректор, B — каждый участник, C — все совместно Определяет процедуру избрания и подписания документов (критично)
Подтверждение решений Требуется ли подписание решений всеми подписантами Определяет процедуру нотариального заверения и подписания (критично)
Обязательный аудит Требуется ли обязательный аудит годовой отчётности Включает задачу «Проведение обязательного аудита» в шаблон
Ревизионная комиссия Предусмотрена ли ревизионная комиссия Включает задачу «Создание/обновление ревизионной комиссии»
Совет директоров Предусмотрен ли совет директоров уставом Определяет набор задач для совета директоров

Исполнительный орган — детали

Тип Описание Влияние
A Единоличный исполнительный орган (генеральный директор) Задача «Избрание генерального директора» включена. Избрание на 5 лет.
B Каждый участник — директор Задача «Избрание генерального директора» исключена. Каждый участник управляет самостоятельно.
C Коллегиальный исполнительный орган (все совместно) Задача «Избрание генерального директора» исключена. Решения принимаются совместно.

Как параметры влияют на шаблоны

При создании организационного мероприятия система анализирует параметры устава и автоматически включает или исключает задачи из шаблона:

  • DecisionConfirmationByAllSign — определяет, требуется ли нотариальное заверение решений
  • ExecutiveBody — определяет, нужна ли задача избрания генерального директора
  • MandatoryAudit — определяет, включать ли задачу обязательного аудита
  • HasRevisionCommission — определяет, включать ли задачу ревизионной комиссии
  • BoardRegulationDocumentId — определяет, нужен ли Положение о Совете директоров
Примечание: Для ООО параметры «Количество акционеров» и «Тип устава» (типовой/нетиповой) не влияют на автоматическую генерацию задач, но учитываются при расчёте кворума ОСУ.

Типовой устав vs Нетиповой устав

Для ООО доступны 36 типовых уставов (Приказ № 411 от 01.08.2018). При выборе типового устава параметры автоматически заполняются из справочника. При переключении на «Нетиповой устав» параметры можно задавать вручную.
