# Бизнес-процесс «Проведение первого заседания Совета директоров»

Первый этап жизненного цикла Совета директоров — первое (организационное) заседание,
на котором избираются председатель, заместитель председателя, секретарь СД и формируются комитеты.

## Структура шаблона

Шаблон `FIRST_BOARD` использует трёхуровневую иерархию:

```
Intent (Цель) → Stage (Этап) → Offer (Шаблон задачи)
```

Каждый офер — это шаблон одной будущей задачи. При инстанцировании каждый офер порождает ровно одну runtime-задачу.

**Признаки шаблона**: АО ✓, ООО ✓, Совет директоров ✓.

## План-график

| Этап | Оферов (задач) | Предшествующий этап | Последующий этап | Сроки проведения |
|------|----------------|--------------------|--------------------|--------------------|
| [1. Подготовка (до заседания)](01-preparation.md) | 9 | — | Этап 2 | До даты заседания; уведомление членов СД — не позднее срока, установленного внутренними документами Организации (рекомендуемый срок — 15 календарных дней) |
| [2. Проведение первого заседания](02-meeting.md) | 18 | Этап 1 | Этап 3 | **Не позднее N дней от даты утверждения состава СД на ОСА.** N устанавливается во внутренних документах Организации, по умолчанию в системе — 30 дней |
| [3. После заседания (результаты)](03-post-meeting.md) | 16 | Этап 2 | — | Протокол — не позднее 3 календарных дней после завершения этапа 2 (даты проведения заседания) ([ст. 68 п. 4 208-ФЗ](../laws/article-68.md)) |

Всего: **43 офера (задачи)**.

## Признаки включения задач (предикаты)

Каждый офер может иметь условия включения — задача создаётся только при совпадении:

| Предикат | Поле | Описание |
|----------|------|----------|
| Нотариус | `require_notary_confirmation` | Только при нотариальном подтверждении решений |
| Подписание всеми | `require_all_sign_confirmation` | Только при подписании всеми участниками |
| Комитеты | `require_committees` | Только при обязательных комитетах СД |
| Положение о СД | `require_board_regulation` | Только при наличии Положения |
| Нетиповой устав | `require_custom_charter` | Только для индивидуального устава |
| Гендиректор | `require_executive_body_a` | Только для исполнительного органа типа A |
| Совет директоров | `require_board_of_directors` | Только если сформирован СД |
| ЮЗЭДО | `require_document_flow_legal_electronic` | Только при электронном документообороте |

Кроме того, если оферу назначена должность в СД (`assigned_board_role_id`), задача
создаётся только при наличии этой должности в текущем составе Совета директоров.

## Нормативная база

- Федеральный закон от 26.12.1995 № 208‑ФЗ «Об акционерных обществах», [ст. 66–68](../laws/README.md)
- Федеральный закон от 08.02.1998 № 14‑ФЗ «Об обществах с ограниченной ответственностью»
- Федеральный закон от 06.04.2011 № 63‑ФЗ «Об электронной подписи»
- Гражданский кодекс РФ, ст. 181.2 (решения собраний)
