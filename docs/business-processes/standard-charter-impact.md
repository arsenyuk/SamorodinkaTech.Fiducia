# Влияние параметров типового устава на бизнес-процессы Fiducia

36 типовых уставов ООО (Приказ Минэкономразвития № 411 от 01.08.2018) содержат 7 параметров. Пять из них напрямую влияют на процессы, обслуживаемые системой Fiducia.

---

## Карта влияния

| Параметр | Значение | Бизнес-процесс Fiducia | Правовое основание |
|---|---|---|---|
| **ExecutiveBody** | **A** — гендиректор | ✓ Избрание/переизбрание директора на ОСУ (срок 5 лет). ✓ Контроль истечения срока полномочий. ✓ Подписание документов гендиректором как единоличным органом. | ст. 40 14-ФЗ |
| | **B** — каждый участник = директор | ✓ Каждый участник действует от имени общества без доверенности. ✓ Нет процедуры избрания директора. ✓ Подписание — любой участник. | ст. 40 14-ФЗ |
| | **C** — все участники совместно | ✓ Решения принимаются всеми участниками совместно. ✓ Документы подписываются всеми участниками. ✓ Нет единоличного органа. | ст. 40 14-ФЗ |
| **DecisionConfirmationByAllSign** | **true** — подписание всеми | ✓ Протокол ОСУ подписывается всеми участниками. ✓ **Не требуется нотариус.** ✓ Система генерирует листы подписания для всех участников. | п. 3 ст. 67.1 ГК РФ |
| | **false** — нотариальное | ✓ Протокол заверяется нотариусом. ✓ Система формирует пакет для нотариуса. ✓ Внешний процесс (не автоматизируется). | п. 3 ст. 67.1 ГК РФ |
| **PreemptiveRight** | **true** — есть | ✓ При продаже доли третьему лицу — **обязательная рассылка оферт** участникам. ✓ Дедлайн 30 дней на акцепт оферты. ✓ Система отслеживает сроки и фиксирует отказы/акцепты. | п. 4 ст. 21 14-ФЗ |
| | **false** — нет | ✓ Продажа доли без приоритета участников. ✓ Оферты не требуются. | п. 4 ст. 21 14-ФЗ |
| **TransferToThirdPartiesWithoutConsent** | **false** — с согласия | ✓ Продажа доли третьему лицу требует **согласия участников**. ✓ Система запускает голосование ОСУ. ✓ Решение — большинством голосов (если уставом не предусмотрено иное). | п. 2 ст. 21 14-ФЗ |
| | **true** — без согласия | ✓ Продажа доли третьему лицу без голосования. | п. 2 ст. 21 14-ФЗ |
| **TransferToParticipantsWithoutConsent** | **false** — с согласия | ✓ Переход доли к другому участнику требует **согласия остальных**. ✓ Система запускает опрос/голосование. | п. 2 ст. 21 14-ФЗ |
| | **true** — без согласия | ✓ Переход доли между участниками без согласования. | п. 2 ст. 21 14-ФЗ |
| **ExitAllowed** | **true** — разрешён | ✓ Участник вправе выйти из общества. ✓ Система запускает процедуру выкупа доли обществом. ✓ Распределение доли между оставшимися участниками в течение года. | ст. 26 14-ФЗ |
| | **false** — запрещён | ✓ Выход участника невозможен (кроме продажи доли). | ст. 26 14-ФЗ |
| **InheritanceWithoutConsent** | **false** — с согласия | ✓ Переход доли к наследникам требует **согласия участников**. ✓ Система запускает голосование. | ст. 21 14-ФЗ |
| | **true** — без согласия | ✓ Наследники вступают в права без согласования. | ст. 21 14-ФЗ |

## Резюме по критичности

| Уровень | Параметр | Почему |
|---|---|---|
| 🔴 Критичный | **ExecutiveBody** | Определяет: нужна ли процедура избрания директора, кто подписывает документы, срок полномочий |
| 🔴 Критичный | **DecisionConfirmationByAllSign** | Определяет: нотариус (внешний) или подписание всеми (внутренний процесс) |
| 🟡 Значимый | **PreemptiveRight** | Запускает оферты с дедлайном 30 дней при каждой продаже доли |
| 🟡 Значимый | **TransferToThirdPartiesWithoutConsent** | Требует голосования ОСУ при продаже доли третьему лицу |
| 🟡 Значимый | **TransferToParticipantsWithoutConsent** | Требует голосования при переходе доли между участниками |
| 🟢 Умеренный | **ExitAllowed** | Запускает процедуру выкупа доли при выходе участника |
| 🟢 Умеренный | **InheritanceWithoutConsent** | Требует голосования при наследовании доли |
