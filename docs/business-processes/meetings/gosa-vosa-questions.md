## Бизнес-процесс: Вопросы, рассматриваемые ГОСА и ВОСА (ПАО и НАО)

### 1. Источники

- [Статья 47](../laws/208-fz/article-47.md) 208-ФЗ — общее собрание акционеров: виды, периодичность, обязательная повестка ГОСА
- [Статья 48](../laws/208-fz/article-48.md) 208-ФЗ — компетенция общего собрания акционеров (исчерпывающий перечень)
- [Статья 55](../laws/208-fz/article-55.md) 208-ФЗ — внеочередное общее собрание (ВОСА)
- [Статья 65.3 ГК РФ](../laws/article-gk-65.3.md) — органы корпорации, возможность передачи части вопросов СД в НАО
- [Статья 66.3 ГК РФ](../laws/article-gk-66.3.md) — публичные и непубличные общества

### 2. Виды общих собраний акционеров

| Вид | Периодичность | Созывающий орган |
|-----|---------------|------------------|
| **ГОСА** — годовое общее собрание | Ежегодно, с 1 марта по 30 июня (п. 3 ст. 47) | Совет директоров |
| **ВОСА** — внеочередное общее собрание | По мере необходимости | СД, ревизионная комиссия, аудитор, акционеры с ≥10% голосов (ст. 55) |

---

### 3. Обязательная повестка ГОСА (п. 3 ст. 47 208-ФЗ)

Эти вопросы **не могут быть исключены** из повестки ГОСА. Перенос в компетенцию СД невозможен ни для ПАО, ни для НАО.

| № | Обязательный вопрос | Правовое основание |
|---|---------------------|-------------------|
| 1 | Избрание совета директоров (наблюдательного совета) | п. 1 ст. 66 |
| 2 | Избрание ревизионной комиссии (ревизора) — если обязательно по закону или уставу | п. 1 ст. 85 |
| 3 | Назначение аудиторской организации или индивидуального аудитора — при обязанности аудита | ст. 5 307-ФЗ |
| 4 | Распределение прибыли (в т.ч. выплата дивидендов) и убытков по результатам отчётного года | пп. 11, 11.1 п. 1 ст. 48 |
| 5 | Утверждение годового отчёта и годовой бухгалтерской (финансовой) отчётности | пп. 11 п. 1 ст. 48 |

> Различие ПАО / НАО по п. 2 и 3: для ПАО ревизионная комиссия обязательна всегда (ст. 85). Для НАО — только если предусмотрена уставом или если общество подпадает под обязательный аудит (выручка > 800 млн или активы > 400 млн — ст. 5 307-ФЗ).

### 4. Остальные вопросы компетенции общего собрания (ст. 48 208-ФЗ)

Могут быть включены в ГОСА или ВОСА. В **НАО** некоторые из них можно передать в компетенцию СД уставом. В **ПАО** — нельзя, все вопросы остаются у ОСА.

| Вопрос | ПАО | НАО |
|--------|-----|-----|
| Внесение изменений и дополнений в устав, утверждение новой редакции устава | Только ОСА | Только ОСА |
| Реорганизация общества | Только ОСА | Только ОСА |
| Ликвидация общества, назначение ликвидационной комиссии | Только ОСА | Только ОСА |
| Определение количества, номинальной стоимости, категории объявленных акций и прав по ним | Только ОСА | Только ОСА |
| Увеличение уставного капитала путём увеличения номинала или размещения доп. акций | Только ОСА | Можно передать СД |
| Уменьшение уставного капитала путём уменьшения номинала, погашения части акций | Только ОСА | Можно передать СД* |
| Избрание членов совета директоров и досрочное прекращение полномочий | Только ОСА | Только ОСА** |
| Образование единоличного исполнительного органа (генерального директора) | Только ОСА*** | Можно передать СД |
| Досрочное прекращение полномочий ЕИО | Только ОСА*** | Можно передать СД |
| Избрание членов ревизионной комиссии и досрочное прекращение | Только ОСА | Только ОСА |
| Утверждение аудитора | Только ОСА | Можно передать СД |
| Выплата (объявление) дивидендов по результатам года | Только ОСА | Только ОСА |
| Утверждение внутренних документов (положение о СД, о ревизионной комиссии и т.д.) | Только ОСА | Можно передать СД |
| Принятие решений об одобрении крупных сделок (> 50% активов) | Только ОСА | Только ОСА |
| Принятие решений об участии в других организациях | Только ОСА | Можно передать СД |

> `*` — кроме обязательного уменьшения УК по закону (чистые активы ниже УК)
> `**` — в НАО кумулятивное голосование при выборах СД — по желанию устава, в ПАО — обязательно
> `***` — если уставом ПАО это не отнесено к компетенции СД

### 5. ВОСА — внеочередное собрание (ст. 55 208-ФЗ)

#### 5.1. Кто вправе созывать

| Инициатор | Условие |
|-----------|---------|
| Совет директоров | По своей инициативе |
| Ревизионная комиссия (ревизор) | Требование, обязательное для СД |
| Аудитор | Требование, обязательное для СД |
| Акционер(ы) с ≥ 10% голосующих акций | Требование с указанием вопросов повестки и формы проведения |

#### 5.2. Что может рассматривать ВОСА

Любые вопросы компетенции общего собрания (таблица раздела 4), если их решение не требует обязательного проведения ГОСА.

#### 5.3. Сроки созыва ВОСА (ст. 55)

- СД обязан принять решение о созыве или об отказе в течение **5 дней** с даты предъявления требования
- Если СД не принял решение или отказал — инициатор вправе созвать собрание **самостоятельно**
- ВОСА должно быть проведено в течение **40 дней** с момента предъявления требования (если вопрос об избрании СД — **75 дней**)
- Дата составления списка акционеров — не ранее чем за **10 дней** до даты ВОСА (для вопросов об избрании СД — **35 дней**)

| Компетенция | ПАО | НАО |
|-------------|-----|-----|
| Обязательная повестка ГОСА (5 вопросов) | Только ОСА | Только ОСА |
| Изменение устава, реорганизация, ликвидация | Только ОСА | Только ОСА |
| Увеличение / уменьшение УК | Только ОСА | Можно передать СД |
| Формирование исполнительных органов | Только ОСА (если устав не отнёс к СД) | Можно передать СД |
| Утверждение аудитора | Только ОСА | Можно передать СД |
| Утверждение внутренних документов | Только ОСА | Можно передать СД |
| Кумулятивное голосование при выборах СД | Обязательно | По желанию устава |
| Ревизионная комиссия | Обязательна | По желанию устава (или при обязательном аудите) |
| Одобрение крупных сделок > 50% активов | Только ОСА | Только ОСА |

### 7. Типичные ошибки при формировании повестки

1. **Не включён обязательный вопрос** — протокол ГОСА будет недействителен
2. **Вопросы сформулированы как информационные**, а не как проекты решений (на собрании голосуют ЗА/ПРОТИВ, а не «принимают к сведению»)
3. **Превышение компетенции** — вопрос, отнесённый к компетенции СД, вынесен на ОСА
4. **В НАО используют повестку ПАО** — не используют право передать часть вопросов СД, перегружая собрание
5. **Нарушен срок уведомления** — не менее 20 дней до ГОСА, 50 дней до ОСА с повесткой об избрании СД
