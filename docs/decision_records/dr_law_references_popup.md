# ADR‑025: Ссылки на законы в Board Portal открываются во всплывающем окне

**Дата:** 2026-08-20  
**Статус:** Принято  
**Контекст:** В Board Portal ссылки на статьи законов (14-ФЗ, 208-ФЗ, ГК РФ и др.) встречаются на множестве страниц: повестка ОСУ, шаблоны задач, thôngационные баннеры, форма создания требований. Переход по ссылке открывает страницу закона в том же окне, что сбивает пользователя с контекста текущей задачи.

**Решение:** Все ссылки на статьи законов в Board Portal открываются во **всплывающем окне** (модальное окно / popover), а не через навигацию.

**Реализация:**
1. Создать компонент `LawReferenceLink` — рендерит ссылку, которая при клике открывает модальное окно с содержимым статьи.
2. Модальное окно: заголовок «Статья закона», тело — Markdown-контент, кнопка «Закрыть».
3. Загрузка контента: HTTP-запрос к `/laws/{articlePath}.md` (существующий механизм из ADR‑024).
4. Ссылки в коде заменяются на компонент:
   ```razor
   <LawReferenceLink Article="article-14fz-31-1" Text="ст. 31.1 14-ФЗ" />
   ```
5. CSS: модальное окно поверх контента (z-index: 1050), закрытие по крестику или клику вне окна.

**Компромиссы:**
- Модальное окно не заменяет полноценную навигацию — для чтения нескольких статей подряд пользователю потребуется открывать каждую отдельно
- Альтернатива: отдельная страница «Справочная информация» с деревом статей — отложено до расширения документации

**Последствия:**
- Пользователь не теряет контекст текущей задачи при изучении закона
- Единообразное поведение для всех ссылок на законы в Board Portal
- компонент переиспользуется на всех страницах, где есть ссылки на ФЗ
