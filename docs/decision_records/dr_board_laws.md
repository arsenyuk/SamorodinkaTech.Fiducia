# ADR‑024: Доставка статей законов в Board Portal через wwwroot

**Дата:** 2026-08-06  
**Статус:** Принято  
**Контекст:** Board Portal должен отображать тексты законов (14-ФЗ, 208-ФЗ, ГК РФ) для пользователей-директоров. Первоначально использовался файловый доступ через `System.IO.File` с путём `ContentRootPath/../docs/laws/`, что приводило к ошибкам из-за точек в именах файлов (Blazor-роутинг не поддерживает точки в URL-параметрах) и проблем с кодировкой путей.

**Решение:**
1. Статьи законов копируются из `docs/laws/` в `SamorodinkaTech.Fiducia.BoardPortal/wwwroot/laws/` — статическая директория, раздаваемая Kestrel напрямую.
2. BoardLaw.razor загружает Markdown через HTTP-запрос к `/laws/{articlePath}.md` с использованием `IHttpClientFactory`.
3. В URL вместо точек используются дефисы (`article-14fz-31-1`), что совместимо с Blazor-роутингом.
4. `docs/laws/` остаётся каноническим источником для разработчиков; wwwroot — runtime-копия.

**Компромиссы:**
- Требуется дублирование файлов при изменении закона (обновить `docs/laws/` + перезапустить приложение для копирования в wwwroot)
- Альтернатива: embedded resources (без wwwroot) — но требует перекомпиляции при изменении текста закона

**Последствия:**
- Законодательные статьи доступны в Board Portal по `/board-law/{article}` без файловых ошибок
- Исходная документация в `docs/laws/` остаётся неизменной
