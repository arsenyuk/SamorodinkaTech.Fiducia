# RBAC: Admin Console

> Связанные документы: [RBAC Board Portal](rbac-board.md)

## Роли системы

| Код | Наименование | Назначаемая | Назначение |
|-----|-------------|-------------|------------|
| `SYS_ADMIN` | Системный администратор | Нет | Полный доступ. Только через LDAP-группу `cn=SysAdmins` |
| `LE_ADMIN` | Администратор ЮЛ | Да | Управление конкретным ЮЛ |
| `SECRETARY` | Секретарь | Да | Организация заседаний, протоколы |
| `CEO` | Генеральный директор (ЕИО) | Да | Руководство юрлицом |
| `CHAIR_BOARD` | Председатель СД | Нет | Председательствование на заседаниях СД |
| `MEMBER_BOARD` | Член СД | Нет | Участие в заседаниях СД |
| `DEPUTY_CHAIR` | Зам. председателя СД | Нет | Замещение председателя |
| `EXTERNAL_DIRECTOR` | Внешний/Независимый директор | Нет | Независимый директор. Назначается через онбординг |
| `PARTICIPANT` | Участник ООО | Да | Участие в управлении ООО |
| `LAWYER` | Юрист | Да | Доступ к юридическим документам |
| `COMMITTEE_CHAIR` | Председатель комитета | Нет | Председатель комитета СД |
| `COMMITTEE_MEMBER` | Член комитета | Нет | Член комитета СД |
| `SHAREHOLDER` | Акционер | Нет | Участие в ОСА АО |

> **Назначаемая** — роль можно добавить/удалить через UI (вкладка «Роли» в карточке пользователя). Неназначаемые роли управляются только через LDAP или бизнес-процессы.

## Доступ к Admin Console

Admin Console доступен для `SYS_ADMIN` и `LE_ADMIN`. API-эндпоинты проверяют `RequireRole("SYS_ADMIN")`.

**Scope LE_ADMIN:** Администратор ЮЛ видит только те юридические лица, в которых он является `EcosystemParticipant` (связь через `User.Login → EcosystemParticipants.LegalEntityId`). Доступны: Главная, Общества, Сотрудники и доступ, Справочники (просмотр).

| Раздел | Путь | Доступ | Меню |
|--------|------|--------|------|
| Главная | `/main` | SYS_ADMIN, LE_ADMIN | Первый пункт (после входа) |
| Общества (список ЮЛ) | `/legal-entities` | SYS_ADMIN, LE_ADMIN | Общества |
| Сотрудники и доступ | `/access-management?le={id}` | SYS_ADMIN, LE_ADMIN | Через Общества |
| Справочники | `/dictionaries` | SYS_ADMIN, LE_ADMIN | Справочники |
| Пользователи | `/users` | SYS_ADMIN | Не в меню (прямой URL) |
| Советы директоров | `/board-of-directors-list` | SYS_ADMIN | Совет СД |
| Общие собрания (ОСА/ОСУ) | `/osa` | SYS_ADMIN | Через Справочники |
| Шаблоны уведомлений | `/notification-templates` | SYS_ADMIN | Шаблоны уведомлений |
