| Элемент | Формат | Пример |
|---------|--------|--------|
| Код в БД | `UPPER_SNAKE_CASE`, 50 символов | `SHARE_REQUEST_ACCEPTED` |

## Структура шаблона тела письма

```
Обращение: «Уважаемый(-ая) {ФИО}!» или «Уважаемый Генеральный директор!»

Суть: 1-2 предложения о произошедшем событии

Детали: конкретные данные (тип запроса, наименование ЮЛ, комментарий и т.д.)

Ссылка: «Подробности: {url}» или «Ознакомьтесь: {url}»
```

## Кто является получателем

| Сценарий | Получатель | Как определить |
|----------|-----------|----------------|
| Заседание СД | Члены СД | `User` → `UserRole` (role = `MEMBER_BOARD`) + `BoardMember.UserId` |
| Запрос принят ГД | Автор запроса | `ShareRequest.CreatedBy` → `User` |
| Коллективный запрос принят | Участники запроса | `ShareRequestSupport` → `BoardParticipant` → `Person` → `User` |
| Запрос виден всем ГД | Ген. директора | `UserRole` (role = `CEO`) → `User` |
| Номинация председателя | Члены СД | `BoardMembers` с `UserId` |
| Согласие на должность | Кандидат | `BoardMember.UserId` |
