# Нередактируемые справочники

## Назначение документа

Описание всех справочников (`ref_*` таблицы) системы Fiducia, их роли в бизнес-логике и E2E-тестах, которые их проверяют.

Все справочники — **нередактируемые**. Данные загружаются из seed-скрипта (`tools/db/02_seed.sql`) и не имеют CRUD-интерфейса в Admin Console. Доступны только для просмотра через страницы `/dictionaries`.

**Связанные документы:**
- [E2E-тесты](../e2e-tests.md) — техническая реализация тестов
- [E2E-сценарии](../e2e-scenarios.md) — бизнес-сценарии сквозных тестов

## Группировка в Admin Console

Страница `/dictionaries` выводит справочники, сгруппированные по разделам:

1. **Роли и уведомления** — Роли, Типы уведомлений
2. **Совет директоров** — Статусы СД, Типы директоров, Должности в СД, Статусы назначений, Причины сложения полномочий, Сроки полномочий ГД
3. **Заседания и голосование** — Формы проведения заседаний, Формы ОСА/ОСУ, Способы подтверждения протоколов
4. **Юридические лица и уставы** — ОКОПФ, Типовые уставы
5. **Документы и требования** — Типы требований, Типы документов, Способы доступа, Причины отказа, Виды ДУЛ
6. **Системные** — Единицы измерения, Месяцы
