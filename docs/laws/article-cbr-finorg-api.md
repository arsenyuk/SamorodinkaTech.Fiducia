# Веб-сервис получения данных об участниках финансового рынка (Банк России)

> **Источник:** [cbr.ru/development/finorg/](https://cbr.ru/development/finorg/)
>
> **Адрес сервиса:** [cbr.ru/FO_ZoomWS/FinOrg.asmx](https://cbr.ru/FO_ZoomWS/FinOrg.asmx)

Веб-сервис Банка России предоставляет актуальную информацию (по состоянию на 23:59 предыдущего дня) об участниках финансового рынка (УФР) в объёме данных, предусмотренных сервисом «[Участники финансового рынка](https://cbr.ru/finorg/)».

---

## Назначение сервиса

Сервис позволяет получать:

- **Общие сведения** об участниках финансового рынка (наименование, регистрационные данные, контактная информация).
- **Информацию о лицензиях** — наличие права на осуществление деятельности на финансовом рынке.
- **Сведения о подразделениях** кредитных организаций (филиалы, дополнительные офисы, мобильные офисы, удалённые точки обслуживания).

---

## Основные методы

### Вспомогательные методы

| Метод | Назначение | Результат |
|-------|------------|-----------|
| `GetLastUpdate` | Дата последнего обновления данных | `dateTime` |
| `EnumFOTypes` | Список кодов типов УФР | XML-справочник |
| `EnumFOVids` | Список кодов видов деятельности | XML-справочник |
| `EnumRegions` | Список субъектов РФ с кодами ОКАТО | XML-справочник |

### Методы получения полной информации

| Метод | Аргументы | Описание |
|-------|-----------|----------|
| `GetFullInfoByID` | `id` (long) | Информация об УФР по внутреннему идентификатору |
| `GetFullInfoByINN` | `INN` (long) | Информация об УФР по ИНН |
| `GetFullInfoByOGRN` | `OGRN` (long) | Информация об УФР по ОГРН |
| `GetBranchesInfoByID` | `id` (long), `page` (int) | Подразделения кредитной организации |

### Методы поиска

| Метод | Аргументы | Описание |
|-------|-----------|----------|
| `Search` | `Name`, `Addr`, `Status`, `FoType`, `VidID`, `OKATO`, `page` | Поиск по наименованию и параметрам |
| `SearchByINNs` | `INNs` (Int64[]) | Массовый поиск по массиву ИНН |
| `SearchByOGRNs` | `OGRNs` (Int64[]) | Массовый поиск по массиву ОГРН |
| `SearchByLicNum` | `licNumber`, `FoType`, `VidID`, `OKATO`, `page` | Поиск по номеру лицензии |
| `SearchByLicDate` | `qType`, `FromDate`, `ToDate`, `FoType`, `VidID`, `OKATO`, `page` | Поиск по датам действия лицензии |

## Структура ответа (GetFullInfoByID / GetFullInfoByINN / GetFullInfoByOGRN)

Основные поля ответа:

| Поле | Описание | Тип |
|------|----------|-----|
| `ID` | Внутренний идентификатор УФР | long |
| `OGRN` | ОГРН | long |
| `INN` | ИНН | string |
| `ShortName` | Краткое наименование | string |
| `Name` | Полное наименование | string |
| `EngName` | Наименование на английском языке | string |
| `Address` | Адрес местонахождения | string |
| `Phones` | Телефоны | string |
| `Email` | Email | string |
| `Status` | Статус: `Active` / `NotActive` | FoStatus |
| `FOTypes` | Коды типов УФР | string[] |
| `LicList` | Список лицензий | LicInfo[] |
| `WebSites` | Интернет-ресурсы | string[] |
| `Fund` | Информация об уставном капитале (для КО) | Fund |

### Структура LicInfo (информация о лицензии)

| Поле | Описание | Тип |
|------|----------|-----|
| `VidID` | Код вида деятельности | int |
| `VidD` | Наименование вида деятельности | string |
| `LIC_Number` | Номер лицензии | string |
| `LIC_Name` | Наименование лицензии | string |
| `LIC_DTStart` | Дата начала действия | dateTime |
| `LIC_DTEnd` | Дата прекращения действия | dateTime |

## Примеры использования

### Получение информации по ИНН

```
POST https://cbr.ru/FO_ZoomWS/FinOrg.asmx/GetFullInfoByINN
Content-Type: application/x-www-form-urlencoded

INN=7710140679
```

### Поиск по наименованию

```
POST https://cbr.ru/FO_ZoomWS/FinOrg.asmx/Search
Content-Type: application/x-www-form-urlencoded

Name=Сбербанк&Status=Active&page=0
```

---

## Примечания

- Данные обновляются ежедневно (по состоянию на 23:59 предыдущего дня).
- Методы `Search` и `SearchByLicNum` при отсутствии фильтрации по виду деятельности могут возвращать дублирующие записи (один УФР может иметь несколько лицензий).
- Тестовое приложение на C# доступно на странице сервиса.
