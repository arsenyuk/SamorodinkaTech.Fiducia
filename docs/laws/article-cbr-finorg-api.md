# Веб-сервис получения данных об участниках финансового рынка (Банк России)

> **Источник:** [cbr.ru/development/finorg/](https://cbr.ru/development/finorg/)
>
> **Адрес сервиса:** [cbr.ru/FO_ZoomWS/FinOrg.asmx](https://cbr.ru/FO_ZoomWS/FinOrg.asmx)

Веб-сервис Банка России предоставляет актуальную информацию (по состоянию на 23:59 предыдущего дня) об участниках финансового рынка (УФР) в объёме данных, предусмотренных сервисом «[Участники финансового рынка](https://cbr.ru/finorg/)».

---

## Назначение сервиса

Сервис позволяет получать:

- **Общие сведения** об участниках финансового рынка (наименование, регистрационные данные, контактная информация).
- **Информацию о лицензиях** — наличие права на осуществление деятельности на финансовом рынке.
- **Сведения о подразделениях** кредитных организаций (филиалы, дополнительные офисы, мобильные офисы, удалённые точки обслуживания).

| Метод | Аргументы | Описание |

## Ключевые фильтры поиска: FoType и VidID

Сервис использует **два независимых фильтра** для классификации участников рынка:

| Фильтр | Назначение | Справочник |
|--------|-----------|-----------|
| `FoType` | **Тип организации** (банковская, страховая, профессиональный участник и т.д.) | `EnumFOTypes` |
| `VidID` | **Вид деятельности** (лицензия) | `EnumFOVids` |

**Важно:** `FoType` и `VidID` — не эквивалентны. Одна организация может иметь несколько типов и несколько лицензий.

## Поиск конкретных типов участников рынка

### Регистраторы (лицензия на ведение реестра)

**Признак:** `VidID=4` (вид деятельности = «Ведение реестра владельцев ЦБ»).

> Почему не `FoType=PT`? Тип `PT` (профессиональные участники) включает брокеров, дилеров, управляющих, депозитарии — **около 600 организаций**. `VidID=4` узко и однозначно определяет регистраторов — **35 организаций**.

```
<tns:Search>
  <tns:Status>Active</tns:Status>
  <tns:FoType></tns:FoType>       <!-- пусто: ищем по VidID -->
  <tns:VidID>4</tns:VidID>        <!-- ← регистраторы -->
  <tns:OKATO>-1</tns:OKATO>
  <tns:page>0</tns:page>
</tns:Search>
```

### Информационные агентства (аккредитованные)

**Признак:** `FoType=IA` (тип организации = «Аккредитованные информационные агентства») или `VidID=52` (вид деятельности = «Раскрытие информации о ЦБ»).

> Оба фильтра возвращают **одинаковые 5 записей**: АНО «АЗИПИ», АО «АЭИ «ПРАЙМ», ЗАО «АКМ», ООО «Интерфакс – ЦРКИ», ООО «СКРИН».

```
<tns:Search>
  <tns:Status>Active</tns:Status>
  <tns:FoType>IA</tns:FoType>      <!-- ← информационные агентства -->
  <tns:VidID>-1</tns:VidID>
  <tns:OKATO>-1</tns:OKATO>
  <tns:page>0</tns:page>
</tns:Search>
```

### Кредитные организации

**Признак:** `FoType=BNK` (тип организации = «Кредитная организация»).

```
<tns:Search>
  <tns:Name>Сбербанк</tns:Name>
  <tns:Status>Active</tns:Status>
  <tns:FoType>BNK</tns:FoType>
  <tns:VidID>-1</tns:VidID>
  <tns:OKATO>-1</tns:OKATO>
  <tns:page>0</tns:page>
</tns:Search>
```

## Проверка конкретного ЮЛ через сервис

### Получение полной карточки

```
POST https://cbr.ru/FO_ZoomWS/FinOrg.asmx
SOAPAction: http://web.cbr.ru/GetFullInfoByINN

<tns:GetFullInfoByINN>
  <tns:INN>7704028206</tns:INN>
</tns:GetFullInfoByINN>
```

### Интерпретация результатов

#### 1. Статус организации (`Status`)

| `Status` | Значение | Действие |
|----------|----------|----------|
| `Active` | Организация действует | Проверить лицензии ниже |
| `NotActive` | Организация **не действует** (ликвидирована, реорганизована, исключена из реестра) | **Отказать** в сотрудничестве |
| `Unknown` | Статус не определён | Дополнительная проверка required |

#### 2. Действие лицензий (`LicList`)

Каждая лицензия в списке `LicList` содержит поля:

| Поле | Описание |
|------|----------|
| `VidID` | Код вида деятельности (4 = ведение реестра, 7 = депозитарий и т.д.) |
| `LIC_Number` | Номер лицензии |
| `LIC_DTStart` | Дата начала действия |
| `LIC_DTEnd` | Дата прекращения действия |

**Правило определения статуса лицензии:**

| `LIC_DTEnd` | Интерпретация |
|-------------|---------------|
| `null` (nil) | Лицензия **бессрочная**, действует |
| Дата в будущем | Лицензия действует до указанной даты |
| Дата в прошлом | Лицензия **прекращена/отозвана** указанной датой |

#### 3. Алгоритм проверки

```
1. Вызвать GetFullInfoByINN(inn)
2. Если Status == "NotActive" → ЮЛ не действует → ОТКАЗ
3. Для каждой лицензии в LicList:
   - Если VidID соответствует требуемому виду деятельности
   - Если LIC_DTEnd != null → лицензия отозвана → ПРЕДУПРЕЖДЕНИЕ
   - Если LIC_DTEnd == null → лицензия действует → ОК
4. Если ни одна лицензия не действует → ОТКАЗ
```

### Массовая проверка: поиск ЮЛ с отозванными лицензиями

Метод `SearchByLicDate` позволяет найти организации, у которых лицензии были прекращены в указанный период:

```
POST https://cbr.ru/FO_ZoomWS/FinOrg.asmx
SOAPAction: http://web.cbr.ru/SearchByLicDate

<tns:SearchByLicDate>
  <tns:qType>Q4</tns:qType>
  <tns:FromDate>2024-01-01T00:00:00</tns:FromDate>
  <tns:ToDate>2024-12-31T23:59:59</tns:ToDate>
  <tns:FoType></tns:FoType>
  <tns:VidID>4</tns:VidID>
  <tns:OKATO>-1</tns:OKATO>
  <tns:page>0</tns:page>
</tns:SearchByLicDate>
```

| qType | Логика | Результат |
|-------|--------|-----------|
| `Q1` | Хотя бы **одна** лицензия начала или прекратила действие в периоде | Широкий набор (включая Active с новыми лицензиями) |
| `Q2` | Лицензии, **начавшие** действие в периоде | Только новые лицензии |
| `Q3` | Лицензии, **прекращённые** в периоде | Как Q1 |
| **`Q4`** | **ВСЕ** лицензии VidID=4 прекращены в периоде | **Только полностью потерявшие лицензию** |

**Для массовой проверки регистраторов** используйте `qType=Q4, VidID=4` — вернёт организации, у которых отозвана **вся** лицензия на ведение реестра.

## Примечания

- Данные обновляются ежедневно (по состоянию на 23:59 предыдущего дня).
- Методы `Search` и `SearchByLicNum` при отсутствии фильтрации по виду деятельности могут возвращать дублирующие записи (один УФР может иметь несколько лицензий).
- Протокол: HTTP POST с `application/x-www-form-urlencoded` (не SOAP-envelope). Ответ — XML.
- Аутентификация **не требуется** (сервис бесплатный, без API-ключа).
- Тестовое приложение на C# доступно на странице сервиса.
