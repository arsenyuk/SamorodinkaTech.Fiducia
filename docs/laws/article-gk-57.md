# Статья 57. Реорганизация юридического лица

## Норма

Реорганизация юридического лица (слияние, присоединение, разделение, выделение, преобразование) осуществляется по решению его учредителей (участников) либо органа юридического лица, уполномоченного на то учредительным документом.

## Ключевые положения

| Параметр | Описание |
|----------|----------|
| **Формы** | Слияние, присоединение, разделение, выделение, преобразование |
| **Решение** | Принимается учредителями (участниками) или уполномоченным органом |
| **Для ООО** | Требуется единогласное решение участников (п. 7 ст. 37 14-ФЗ) |
| **Для АО** | Решение принимается общим собранием акционеров |
